# Silly Memories Plus

[Русский](./README.md) | [English](./README.en.md)

Расширение SillyTavern для иерархического сжатия истории чата.

Модель составляет краткое описание старых событий и записи об отношениях, предметах, обещаниях и других важных деталях. Эта память подставляется в запрос вместе со свежими сообщениями. Полная переписка сохраняется в чате, а созданные блоки памяти можно просматривать и редактировать.

## Установка и первый запуск

1. В SillyTavern откройте расширения и нажмите «Установить расширение».
2. Вставьте адрес репозитория: `https://github.com/stellvt/silly-memories-plus`.
3. После установки перезагрузите страницу и откройте настройки Silly Memories Plus.
4. В разделе «Суммаризатор» выберите профиль подключения. Можно использовать отдельную модель для памяти или оставить «Текущий основной API» для основного подключения чата.
5. Нажмите «Проверить суммаризатор», чтобы проверить подключение на коротком примере.
6. Откройте чат. Автоматическое сжатие включено по умолчанию; настройки для начала можно оставить стандартными.

Для ручного запуска нажмите «Сжать историю» в разделе «Состояние и обслуживание». Статус задачи отображается над подменю, рядом находится кнопка «Остановить».

## Как работает память

По умолчанию сжатие начинается при заполнении 75% доступного контекста. На свежую историю отводится 25% окна: эти сообщения отправляются модели целиком. Более старые сообщения превращаются в блок памяти с целевым размером 4000 токенов. Размер блока зависит от объёма исходной истории.

Например, при доступном окне 80 000 токенов порог составляет 60 000, а на свежие сообщения отводится около 20 000 токенов. Порог и долю свежей истории можно менять; их сумма всегда равна 100%.

Уровень блока обозначает, из чего он создан:

- **L1** — саммари исходных сообщений.
- **L2** — объединение нескольких блоков L1.
- **L3 и выше** — дальнейшее сжатие объединённых блоков.

Когда память занимает слишком много места, расширение объединяет подходящие блоки. Это может произойти и раньше порога, если для следующего запроса нужно освободить контекст. Последние два сообщения всегда остаются целиком.

Шкала над подменю показывает, сколько места занимают память, исходная история, закреплённые факты и остальной промпт. На ней отмечены порог сжатия и свободный объём. Размер остального промпта становится известен после подготовки запроса; до этого шкала показывает только известную часть контекста.

## Работа с блоками

### Просмотр и редактирование

Откройте «Память текущего чата». Вкладка «Активные» содержит блоки, используемые при подготовке контекста. В «Архиве» находятся исходные блоки уже выполненных объединений и блоки, чьи исходные сообщения изменились.

Нажмите шапку блока, чтобы раскрыть его. Кнопка «Редактировать» открывает поля прямо в блоке: можно изменить заголовок, описание событий и любую категорию фактов. В списках записывайте каждый пункт с новой строки, затем нажмите «Сохранить блок».

### Регенерация с пожеланием

Выберите блок и нажмите «Регенерировать блок». При желании напишите, что нужно учесть, например: «Сохрани причины ссоры и кому достался ключ». Нажмите «Создать вариант», сравните результат с сохранённым блоком и выберите «Сохранить замену» или «Отбросить вариант».

Если этот блок входит в память более высокого уровня, регенерация также пересобирает зависимые объединения.

### Объединение блоков

Нажмите значки уровня в шапках двух или более соседних активных блоков одного уровня, затем нажмите «Объединить L1 → L2» или соответствующую кнопку для выбранного уровня.

Можно объединить первые два блока L1 и оставить третий отдельным. Исходные блоки объединения будут доступны в архиве. Для объединения выбирайте блоки, использующие саммари.

### Выбор истории и сохранение памяти

«Использовать историю» отправляет модели исходные сообщения выбранного фрагмента. «Использовать саммари» отправляет его сжатый блок. Исходные сообщения занимают больше места; их объём отражается на шкале контекста.

У выбранного блока доступны копирование JSON и экспорт отдельным файлом. «Экспорт JSON» в разделе «Состояние и обслуживание» сохраняет всю память чата, включая закреплённые факты.

«Удалить» убирает выбранный блок и зависимые объединения; для открывшихся участков используется исходная история. «Очистить память чата» очищает все блоки и закреплённые факты после подтверждения. Сообщения чата сохраняются.

## Закреплённые факты

В разделе «Закреплённые факты» вы вручную записываете сведения, которые хотите отправлять модели при каждой генерации в этом чате. Например: «Мира хранит серебряный ключ. Роуэн обещал вернуться до рассвета». Нажмите «Сохранить факты».

Факты сохраняют свой текст при сжатии и регенерации блоков. Они занимают место в контексте и действуют даже при выключенном автоматическом сжатии. Для удаления фактов очистите поле и сохраните его.

## Настройки модели и сжатия

Для памяти можно выбрать отдельный профиль Connection Manager. Основная модель продолжит отвечать в чате через своё подключение.

| Настройка | Что меняет |
| --- | --- |
| Порог сжатия | При какой заполненности контекста запускать сжатие. По умолчанию — 75%. |
| Свежая история | Какая часть окна отводится на последние сообщения целиком. По умолчанию — 25%. |
| Целевой размер блока | Желаемый объём одного саммари. По умолчанию — 4000 токенов. |
| Минимальный объём исходника | Сколько старой истории накопить перед сжатием. При нехватке места сжатие может начаться с меньшего объёма. |
| Входной бюджет суммаризатора | Доступное окно модели, создающей память: для исходника, инструкции и ответа. |
| Лимит токенов ответа | Объём содержательного ответа суммаризатора, отдельно от целевого размера блока. |
| Роль сообщения памяти | От чьего имени память передаётся модели: системы, пользователя или ассистента. |
| Добавлять факты к повествованию | Включать в запрос записи об отношениях, предметах и других деталях вместе с описанием событий. |

Целевой размер задаёт желаемый объём: полный саммари может превышать цель. Расширение проверяет фактическую заполненность контекста перед отправкой запроса модели. При сжатии в несколько этапов каждый готовый блок сохраняется отдельно; если следующая задача не завершится, продолжение начнётся с сохранённой памяти.

Если контекст переполнен, верните некоторые блоки в режим саммари, сократите закреплённые факты или увеличьте окно контекста в SillyTavern.

Интерфейс доступен на русском и английском. По умолчанию используется язык SillyTavern; ручной выбор находится в разделе «Состояние и обслуживание → Язык интерфейса».

## Собственные промпты

В разделе «Промпты суммаризации» можно менять инструкции для трёх задач:

- **История → L1** — создание памяти из сообщений чата.
- **Блоки памяти → объединение** — объединение уже созданных саммари.
- **Большой результат → сжатый блок** — сокращение слишком длинного ответа.

В шаблонах используются `{{target_tokens}}` для целевого размера, `{{level}}` для уровня блока и `{{schema}}` для формата ответа. Сохраняйте требования к формату, чтобы расширение могло прочитать результат.

Пустое поле использует встроенный промпт. «Восстановить промпты» возвращает стандартные инструкции для всех трёх задач.
